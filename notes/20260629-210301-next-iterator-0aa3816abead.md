# 2026-06-29T21:03:01Z typed next iterator slice

Base commit: 0aa3816abead51fb758613a3de49b745ecea0c38

Reference context:
- Ptolemy (019f1526-607b-77b3-936d-b9ab91995ffb) previously found that Teal types `next` through overloaded stdlib declarations: `{K:V}, ?K -> K,V` and `{A}, ?integer -> integer,A`.

Implemented:
- Added parser-only iterator metadata for generic-for forms like `for k, v in next, map, nil do`.
- Derived loop key/value locals from the second expression in the generic-for expression list when the first expression is global `next`.
- Added strict diagnostics for `next` over non-table values.
- Added focused positive/negative TealJIT tests for `next` over maps and arrays.
