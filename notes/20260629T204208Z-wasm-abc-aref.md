# 20260629T204208Z - WASM ABC and AREF lowering

Base commit: 28a4568f

Added the next array-table layer for WASM trace modules:

- `IR_ABC` as an unsigned array-bounds guard
- `IR_AREF` as TValue slot address calculation

`IR_ABC asize idx` lowers to:

```
idx
asize
i32.ge_u
if
  i32.const 0
  return
end
```

`IR_AREF array idx` lowers to:

```
array
idx
i64.extend_i32_u
i64.const 3
i64.shl
i64.add
```

The synthetic trace fixture now emits `ABC`/`AREF` after the table SLOAD and
`tab.asize`/`tab.array` FLOADs. `wasm/tools` asserts `i32.ge_u`,
`i64.extend_i32_u`, and `i64.shl` appear in the lowered module.

Remaining table-array trace work:

- `ALOAD` for typed TValue reads from AREF addresses
- `ASTORE` for typed TValue writes to AREF addresses
- `EQ NULL` guards for metatable checks
- side exits/snapshots instead of the current placeholder `return 0`
