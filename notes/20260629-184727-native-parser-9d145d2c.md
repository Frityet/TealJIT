# 2026-06-29 18:47:27 UTC - native parser milestone - 9d145d2c

Commit anchor: `9d145d2ca3db58493859c495489a0f08f627834f`

What changed:
- `.tl` chunks are detected in `lj_load.c` and enter `lj_teal_parse()`.
- `lj_teal_parse()` is mode glue: it sets `LexState.teal` and strict defaults, then calls the normal LuaJIT parser.
- `lj_parse.c` now has a native Teal parser mode with contextual soft keywords.
- `local record NAME end` emits a real local table, so record namespaces can be used as value containers.
- Function parameters and return lists accept Teal annotations such as `a: integer` and `): integer`.
- Local declarations accept `name?: type`, basic attributes, initializer inference, and strict nil checks.
- Expressions carry small static type tags for literals, locals, arithmetic, comparisons, and `as` casts.
- Strict mode rejects obvious nil/type assignment failures and impossible casts such as `nil as integer`.
- `--#pragma strict off/on` is handled by the lexer in Teal mode.
- CLI support for `-t strict=on/off` was added.

Verification:
- `make -C src clean && make -C src amalg -j2`
- `make -C src clean && make -C src -j2`
- `cd test/tealjit && ./run.sh`

Build note:
- `lj_teal.c` is included by `ljamalg.c` like the other core parser files.
- `lj_teal_option()` is intentionally declared with `LUA_API` so the standalone
  `luajit.o` frontend can call it even when the core is amalgamated, where
  `LJ_FUNC` becomes TU-local.

Current limitations:
- This is not full Teal yet. Type aliases, interfaces, enums, macros, full records, generics, and complete flow typing still need real checker work.
- Type-only aliases currently raise an explicit native-checker diagnostic instead of being silently skipped.
- Record return freezing is not fully wired into bytecode emission yet; record namespace materialization is native, but the frozen-record runtime behavior still needs a VM/compiler design pass.
- No new bytecode opcodes or bytecode dump format changes were made, preserving LuaJIT 2.1 compatibility for this milestone.
