# 2026-06-29 22:17:02 UTC - not narrowing

Base commit: 22a1396cdfad7e178faf3b93e196773189d3ed59

Extended the native Teal flow fact carried by `ExpDesc` with an inversion bit so
`not (value is T)` preserves the same local/type target but flips which side of
the branch keeps matching members. This brings `not` conditions and `not ...
and ...` RHS parsing in line with Teal's boolean-flow semantics without changing
the requested strict-mode behavior.

Implementation notes:

- `teal_expr_set_narrow` still records direct `is` facts as match-side facts.
- Unary `not` toggles `teal_narrow_invert` when the operand has a narrow fact.
- `teal_apply_narrow` flips `keep_matches` for inverted facts, so then/else
  branches and `and` RHS narrowing share the same logic.

Added coverage:

- `test/tealjit/is_union.tl` now checks `not (x is T)` in branches and in
  `not (x is T) and x or fallback`.
- `test/tealjit/not_narrow_type_bad.tl` prevents the unsound case where
  `not (x is string)` would still narrow `x` to `string` in the true branch.
