# 2026-06-29 22:20:41 UTC - while narrowing

Base commit: 9139683c7c4ee4101f1ecefffd544256ba5c53a7

Implemented Teal-compatible condition narrowing for `while` bodies. The parser
now keeps the parsed condition expression from `expr_cond`, applies any native
`is` flow fact while parsing the loop body, and restores the prior local type
before emitting the loop backedge. This mirrors the Teal checker's
`while.before_statements` behavior, where condition facts are applied before the
body statements after loop widening.
