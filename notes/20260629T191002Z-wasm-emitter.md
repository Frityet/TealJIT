## What this slice adds

Add a small reusable WebAssembly binary emitter for future VM/JIT backend work:

- module header writer
- unsigned and signed LEB128 writers
- byte/string/name writers
- section framing
- function type, function import, export, limits, and function-body framing
- common value type, section, external-kind, and opcode constants

The emitter is compiled into normal native builds so it stays syntax-checked
while the WASM64 backend is gated.
