# 2026-06-29 22:12:11 UTC - and narrowing

Base commit: 98206c2422dd2c2677e5073aeb10dd760961229a

Implemented a small Teal-semantics slice for native expression flow: when parsing
`lhs and rhs`, the parser now applies any `is` narrowing fact from `lhs` while
parsing `rhs`, then restores the prior local type immediately afterward. This
matches the upstream Teal behavior that records an `and` fact from the left
expression and types the expression from the right-hand side, while keeping the
existing strict-mode differences intact.
