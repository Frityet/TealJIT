## Goal

Bring this LuaJIT fork toward a full WebAssembly target, scoped to WASM64 first,
including FFI, JIT, GC behavior, host support code/documentation, and optional
WasmGC support.

## Immediate slice

LuaJIT has no existing WebAssembly target in this fork. The first source slice is
to make the target explicit in architecture and build metadata, add a WASM64
target ABI header, and document the host-assisted JIT boundary. Full runtime
execution still requires a WebAssembly VM backend and an IR-to-Wasm emitter.

## Early findings

- `src/lj_arch.h` owns architecture/OS detection and derived feature macros.
- `src/Makefile` derives `TARGET_LJARCH`, picks `vm_<arch>.dasc`, and selects
  DynASM flags for `host/buildvm_arch.h`.
- `src/lj_target.h` includes the per-target register/ABI description used by
  the recorder, assembler, exit state, and FFI paths.
- The current VM requires DynASM assembly (`src/vm_*.dasc`) and a generated
  object (`src/lj_vm.S`/`src/lj_vm.o`); there is no C VM fallback.
- WebAssembly JIT support cannot be a plain RWX memory allocator inside a
  sandboxed module. It needs a host contract that can compile/instantiate
  generated Wasm modules and return callable entries.
